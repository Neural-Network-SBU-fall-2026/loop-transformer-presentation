# How to Loop Your Transformer

An English, motion-rich academic presentation for a 15–20 minute graduate-level talk.

## Deliverables

- Interactive web presentation (React, TypeScript, SVG, GSAP)
- Editable PowerPoint generation pipeline
- PDF export workflow
- Research notes, equations, figures, and source register

## Research integrity

The paper is treated as a preprint, not as a peer-reviewed Q1 journal article. All quantitative claims must be checked against the paper PDF before being presented as results. Conceptual diagrams are labeled as such.
