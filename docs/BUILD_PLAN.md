# Build and Acceptance

## Deliverables
- English-only 16:9 interactive web presentation.
- Editable PowerPoint generated from shared slide content.
- PDF export workflow.
- Research notes and source register.

## Controls
- Arrow Left/Right: navigate.
- Space/PageDown: next slide; PageUp: previous slide.
- Home/End: first/last slide.
- F: fullscreen.
- Autoplay: advance every 9 seconds.

## Acceptance checklist
- [ ] npm install succeeds.
- [ ] npm run build succeeds.
- [ ] Web deck works at 16:9 and on mobile.
- [ ] Keyboard and fullscreen controls work.
- [ ] 12 slides fit 15–20 minutes.
- [ ] PowerPoint generation succeeds and opens in PowerPoint.
- [ ] PDF export checked at 16:9.
- [ ] All quantitative claims traced to paper figures/tables.
- [ ] Conceptual curves are not mistaken for measured results.
- [ ] Slides are English-only.
