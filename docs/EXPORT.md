# Export Guide

## Web
Run npm install and npm run dev. Use a 16:9 desktop viewport. Keyboard navigation is supported. Press F for fullscreen.

## PowerPoint
Run npm run pptx. The generated deck is editable and uses native PowerPoint text and shapes. It is a clean academic companion, not a frame-by-frame export of the web animation.

## PDF
Open the web deck in Chromium and use Print → Save as PDF. Select landscape, margins none, and background graphics on. For a handout-quality PDF, export from PowerPoint after reviewing the PPTX.

## Presenter guidance
Use the presenter notes embedded in the web slide source as a rehearsal guide. Keep the talk within 15–20 minutes.
